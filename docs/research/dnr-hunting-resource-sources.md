# DNR hunting-resource sources: RGMAs and CWD sampling locations

Verified 2026-09-23 (queries ran around midnight US Central, so some server timestamps read 2026-09-24 UTC) against official Minnesota DNR pages, the MnGeo-hosted [`us_mn_state_dnr` REST directory](https://enterprise.gisdata.mn.gov/aghost/rest/services/us_mn_state_dnr), Minnesota Geospatial Commons item metadata, and the DNR-hosted ArcGIS portal items behind the [2026 Deer Hunt and CWD Plan](https://gis.dnr.state.mn.us/arcgis/apps/experiencebuilder/experience/?id=1eea035e49a047a88464306414a632c8). Counts are live-query snapshots, not contractual totals. Answers ticket #14.

## Decision

- **Ruffed Grouse Management Areas (RGMAs): integrate directly.** Use polygon layer 1 of the durable MnGeo FeatureServer. It is anonymous, small (48 polygons, 223 KB as GeoJSON) and not seasonal, and DNR's own wording supports a habitat-designation statement. Class: existing `managed-land` with an RGMA-specific sentence. It covers only northern Minnesota, 46 of 48 records were last edited in 2013 or 2015, and it is a designation overlay, not ownership or access. This settles the stray "Later" line in #10: the amendment already moved RGMAs to selected, and nothing found argues for holding them back.
- **CWD sampling and self-service locations: integrate directly, but only as a season-gated layer with an official-link fallback.** Use layer 1 (sites) filtered to `show = 'Yes'`. There is no MnGeo/Commons copy; the layer lives in the season-named DNR-hosted service, its URL embeds a per-season portal item ID, and the sites layers carry no `effperiod`. A current period is verifiable only indirectly (sibling layer 3 `effperiod` in the same service, item title year, edit dates). If any check fails the layer fails closed and links to [DNR's CWD page](https://www.dnr.state.mn.us/cwd/index.html). Class: existing `facility` plus a dated requirement line; no new class.

## How each URL was found

- **RGMA:** service listed in the MnGeo directory above (`bdry_ruffed_grouse_mgmt_areas`, FeatureServer and MapServer). Item metadata came from the Commons Hub search API ([item `f0149c15...`](https://gis.data.mn.gov/api/search/v1/collections/all/items/f0149c15712f4749893983044e0e92a9)) and its [metadata PDF](https://operations.gis.data.mn.gov/api/publicdownload/download/649/metadata.pdf). The old `gisdata.mn.gov/dataset/...` pages now return 301 to the site root. The [DNR RGMA page](https://www.dnr.state.mn.us/rgma/index.html) loads `maps.dnr.state.mn.us/faw/rgma/rgma.json` (found in the page source); used only as a cross-check: same 48 unit names.
- **CWD:** started from layer 3 (prior ticket), read the FeatureServer directory (layers 0-4), then read the published Experience Builder item data and its web map ([`a7b429a1...`](https://gis.dnr.state.mn.us/arcgis/sharing/rest/content/items/a7b429a199e7496f8fc2dd90087c9edb/data?f=json)) to see which layers DNR's own app uses and with what filters. The DNR [interactive CWD map page](https://www.dnr.state.mn.us/cwd/plan-map.html) embeds that Experience ID. No rendered viewer UI was read.
- **No stable copy:** none of 223 distinct service names in the MnGeo directory relates to CWD, and Hub searches for "chronic wasting", "CWD", "carcass" and "sampling station" return no DNR CWD dataset (only Deer Permit Areas and Deer Harvest). The underlying `gis.dnr.state.mn.us/host/rest/...` service returns `499 Token Required`; only the item-scoped `.../sharing/servers/<itemId>/...` proxy path answers anonymously. Item [`8462b6a8...`](https://gis.dnr.state.mn.us/arcgis/sharing/rest/content/items/8462b6a81c46461484c68d4bd638134c?f=json) is titled `CWD_Sampling_and_Regulations_for_MN_2026_Deer_Seasons_Public_View_SC`, created 2026-06-01, while the path still says `2020`. Portal search lists only 2026 items, so treat next season's URL as new until re-verified.

## Freshness and effective period

- **RGMA has no season.** The [Commons metadata](https://operations.gis.data.mn.gov/api/publicdownload/download/649/metadata.pdf) states Time Period of Content `20250130`, Progress "In work", Update frequency "As needed", and "This coverage is not complete." Feature `editdate` values: 29 polygons 2013-01-08, 17 on 2015-02-09, 1 on 2018-12-04, 1 on 2025-01-16. The Commons item's created/modified stamps (2026-05-12/13) and the PDF's "Last Updated: 09-15-2026" are re-hosting dates, not data edits. Show "Boundary last edited" and never claim currency. DNR's page prose (49 locations, over 100,000 acres, 184 trail miles, 400-4,800 acres per area) disagrees with the layer (48, 70,085 acres, 168.8 miles, 218-3,734 acres); use layer values only.
- **CWD is season-specific and mid-edit.** Layer 1 `last_edited_date` spans 2026-09-17 to 09-21; layer 0 was bulk-edited 2026-09-21. The Experience and web map were modified 2026-09-23, and DNR's web map labels its barrel layer "Self-service sampling at the site (in progress)". Sites layers have no period field. Retired records remain in the table (264 of 398 sites and 228 of 283 barrels are `No`; 177 sites are "no longer available"). DNR's [surveillance-block](https://www.dnr.state.mn.us/cwd/surveillance-block.html) and [management-zone](https://www.dnr.state.mn.us/cwd/management-zone.html) pages still show a banner "Deer hunting ... has concluded for 2022 season" above 2026 content, so page banners are not a freshness signal.
- **Programmatic current-period check (all must pass, else fail closed):** layer 3 distinct `effperiod` equals the configured period (now `July 2026 - June 2027`); the portal item title contains the configured season year; at least one layer-1 row has `show='Yes'`; the newest `last_edited_date` on layer 1 is on or after 1 July of the season year; layer names and field names match this note.

## Coverage and what "no feature here" means

- **RGMA:** 48 units in 13 northern counties (St. Louis 18, Cook 6, Beltrami 5, Itasca 5, and others; longitude -95.93 to -90.15, latitude 45.92 to 48.60; DNR regions 1-3). DNR's page does not say "statewide", and the metadata says the coverage is incomplete. No polygon means only that DNR has not listed an RGMA there; it says nothing about grouse habitat, public land, or hunting eligibility.
- **CWD:** 133 shown sites, latitude 43.51-48.98, longitude -96.99 to -91.56, by `cwdareas`: 45 mandatory-block sampling stations and 17 partner or DNR-office sites labeled "Mandatory or statewide optional" (longitude -95.99 to -93.99, latitude 43.68 to 46.01); 66 "Statewide optional" DNR offices (28) and partners (38) spread across the state; and 5 DPA 236 self-service points in the east metro. DNR says the [surveillance block rotates over four years](https://www.dnr.state.mn.us/cwd/index.html) (south-west in 2026, ending south-east in 2029), so the station set changes wholesale each year. No marker in view does not mean no requirement or no way to test: DNR says testing options exist [throughout Minnesota and all deer seasons](https://www.dnr.state.mn.us/cwd/cwd-testing.html), including mail-in kits. Requirements come from the zone layer and the DNR page, not from marker density.

## Meaning, class, and draft wording

**RGMA** (DNR: "RGMAs are located in areas that have good potential for producing grouse and woodcock and are managed to promote suitable habitat conditions"; "RGMAs are also open to other types of hunting and recreation"; "Respect private property and verify public hunting areas by observing boundary signs"; RGMAs are "maintained in partnership with government land owners, The Ruffed Grouse Society, volunteers, and by DNR wildlife managers" ([RGMA page](https://www.dnr.state.mn.us/rgma/index.html)); map data "do not accurately represent the actual legal or established boundary" ([GPS page](https://www.dnr.state.mn.us/rgma/gps/index.html)); "sites managed for ruffed grouse by MN DNR; sometimes in cooperation with other public land management agencies" ([Commons metadata](https://operations.gis.data.mn.gov/api/publicdownload/download/649/metadata.pdf))). The data show why access cannot be inferred: cooperators include county, federal (`SNF`) and Potlatch entries; DNR's [Hunter Walking Trails layer](https://enterprise.gisdata.mn.gov/aghost/rest/services/us_mn_state_dnr/trans_hunter_walking_trails/FeatureServer/0) lists the Camp Ripley RGMA trail as owned by "Department of Military Affairs, Camp Ripley"; and 10 of 48 polygons touch neither a WMA nor a state forest boundary. The metadata sentence "Off-highway vehicles generally are not allowed on RGMAs" conflicts with several DNR access notes ("This unit allows atv access"), so the popup states no vehicle rule.

- Class: `managed-land` ("Managed land; access restrictions may apply."), extended: "Ruffed Grouse Management Area: a DNR habitat designation for grouse and woodcock on land that can have different owners and managers. It does not show ownership or permission to enter; verify boundary signs and respect private property."
- Links: **Verify current regulations** to the [DNR hunting and trapping regulations](https://www.dnr.state.mn.us/regulations/hunting/index.html) (it currently carries 2024 update notes and "Expired, reference only" labels on some booklets, so recheck at delivery); program link "RGMA information and unit maps" to `https://www.dnr.state.mn.us/rgma/index.html`.

**CWD sampling and self-service locations** (DNR: "In each of the rotational years, CWD testing is mandatory in the surveillance block for any deer harvested during the opening weekend of firearms season that is one year of age or older. All deer permit areas outside of the surveillance block will have voluntary testing options." ([CWD page](https://www.dnr.state.mn.us/cwd/index.html)); management zones: "Testing is voluntary." ([page](https://www.dnr.state.mn.us/cwd/management-zone.html)); surveillance block: staffed stations Nov. 7-8 9 a.m.-7 p.m. and Nov. 9 9 a.m.-noon, "All sampling stations also offer self-service on Saturday, Nov. 7 through Monday, Nov. 9", deer "must be registered before sampling" ([page](https://www.dnr.state.mn.us/cwd/surveillance-block.html)); partner sites: "Testing is free but partners may charge fees for their services" ([page](https://www.dnr.state.mn.us/cwd/cwd-partners.html)); self-service stations are where hunters "provide a sample for CWD testing" ([videos](https://www.dnr.state.mn.us/cwd/videos.html)). A station is a place to provide a sample. It is not a carcass-disposal site: DNR says hunters "may not dispose of carcasses (including head or spine) on public land, including wildlife management areas, state forests, road rights-of-way or in any water body" ([carcass rules](https://www.dnr.state.mn.us/deerimports/index.html)), and DNR's barrel notes (13 records, none currently shown) say a station "will be pulled after the goal is met".)

- Class: `facility` ("Marks a facility or route, not access to adjoining land or permission to take any species.") plus one fixed season line. Draft popup: title "CWD sampling site: {sitename}" with the Season label from layer 3 `effperiod`; that facility sentence; "Listed by DNR for hunters {dpa}"; **Requirement:** {cwdareas}; in-person, self-service, appointment and kit rows from the source text; a partner note when `admin` is Partner; "DNR record last edited {last_edited_date}. Hours and availability change, and stations can close once sampling goals are met. Verify on DNR's CWD page."
- Never say "mandatory" unless a source field or DNR page says so; render `cwdareas` and `dpa` verbatim. Do not describe any point as a place to leave carcasses.
- Links: **Verify current CWD requirements** to `https://www.dnr.state.mn.us/cwd/index.html`; per-record `moredetail` (one of the `surveillance-block`, `cwd-testing` or `management-zone` pages) as the program link.

## Overlap with existing layers

- RGMA polygons overlay, and do not duplicate, Public lands: 11 of 48 intersect a WMA polygon ([`bdry_dnr_wildlife_mgmt_areas_pub` layer 0](https://enterprise.gisdata.mn.gov/aghost/rest/services/us_mn_state_dnr/bdry_dnr_wildlife_mgmt_areas_pub/FeatureServer/0)) and 32 intersect a state forest boundary ([`bdry_state_forest` layer 3](https://enterprise.gisdata.mn.gov/aghost/rest/services/us_mn_state_dnr/bdry_state_forest/FeatureServer/3)); intersection counts, not containment. 36 of 304 Hunter Walking Trail records are named for RGMAs, so the two layers overlap in the field and should be labeled separately.
- CWD sites sit in the same service as the committed CWD zones and add points only; deer permit areas are unaffected.

## Conditions and annual checks

1. **RGMA:** compare layer 1 names with `maps.dnr.state.mn.us/faw/rgma/rgma.json` (48 each today), record max `editdate`, and re-run the `pdf_file` link check.
2. **CWD, each August-September:** follow the DNR CWD map page to the current Experience, web map and service, then re-pin item ID, layer indexes and the `show = 'Yes'` filter; run the current-period check above; confirm the filter still excludes `no longer available` rows. Fail closed and link out if the pointer, title year, `effperiod`, or edit dates do not match.
3. Do not persist or offline-cache CWD points; query live with a short TTL. Add a `gis.dnr.state.mn.us` provider to `src/app/api/gis-proxy/[provider]/[...path]/route.ts` (its `providerRoots` has MnGeo, county and Esri roots but no DNR portal root), limited to the pinned `/arcgis/sharing/servers/<itemId>/rest/services/Hosted/` prefix; the same provider serves the CWD zones layer. RGMA needs no proxy change: `mngeo-features` already covers `enterprise.gisdata.mn.gov/aghost/rest/services/`.
4. Ask DNR whether a season-neutral CWD sampling FeatureServer will be published on MnGeo (add to `docs/licensing/QUESTIONS-FOR-AGENCIES.md` at delivery).

## Licensing and attribution

The Commons item license is `custom`: "No special restrictions beyond those described in the Minnesota Department of Natural Resources General Geographic Data License Agreement" (item and metadata Access/Use Constraints). The CWD item has null `licenseInfo` and `accessInformation`, the web map says only "MN DNR, MNIT", and `copyrightText` is empty, so no more specific license was found and the [DNR General Data and Software License Agreement](https://www.dnr.state.mn.us/sitetools/data_software_license_plain.html) is the fallback. It grants a personal, non-exclusive, non-transferrable, limited license, allows derivative works, bars reselling, distributing or displaying the data "in its entirety" for commercial purposes or otherwise, requires DNR acknowledgment, disclaims accuracy and currency, says geographic data do not establish legal boundaries or access and are not for navigation, and grants no right to use DNR's name or logos. Use live queries, the attribution "Minnesota DNR · reference only, not a legal boundary or proof of access", and no DNR logo. CWD-specific: layer 1 carries individual contact names and private-business phone numbers; show only `phone` (DNR's own popup does) and omit `contact`. A paid, ad-supported, public or offline product needs written DNR permission before either layer is assumed reusable.
