# onX handoff

MnMapping uses documented file interchange and no private onX API. Export GPX for pins and tracks or KML for lines and area shapes, then import the file through onX Hunt's My Content workflow. onX currently documents GPX/KML imports with a 4 MB file limit and a maximum of 3,000 markups; a paid membership is required to import. Styling/icons are not expected to survive generic GPX/KML interchange.

This is an optional handoff. MnMapping's map, public-land layers, parcels, and browser-local My Data remain useful without an onX account.
