# Jackson County

Not legal advice. Access date: 2026-09-18.

## Parcels

MnMapping sources Jackson's parcel polygons via the statewide MnGeo Open Parcels aggregation (11,035 records).
Jackson also **directly sells** its own GIS parcel layer and tabular property-tax data: *"the flat fee for full
data sets of both tabular and the full GIS parcel layer is $100 each,"* released "only upon receipt of full
payment," gated behind a signed **"Jackson County File Extract Disclaimer Statement."** This is a distinct,
county-controlled channel from the statewide aggregation MnMapping actually uses; the disclaimer form's
substantive content was not independently retrievable this session.

Jackson is the only county in its batch with any parcel data live in MnMapping today (via the statewide feed);
the other seven counties in that batch have none.

## Imagery

Only statewide WMS imagery is embedded; Jackson's own 2021 Pictometry flyover (confirmed via the county's own
2021 audit report) is correctly excluded.
