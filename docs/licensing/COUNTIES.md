# All 87 counties

Research and risk classification, not legal advice. "Parcel Source" and "Imagery Source" describe what
MnMapping's code (`src/config/layers/counties/*.ts`) actually queries today, not what's theoretically
available from the county. Counties whose parcels come from the statewide aggregation inherit the GREEN
finding in [STATEWIDE-SOURCES.md](STATEWIDE-SOURCES.md) unless a county-specific note below says
otherwise. A file exists under [COUNTY-DETAILS/](COUNTY-DETAILS/) for counties with genuinely complex
terms — linked in the Notes column where present. Research access date: 2026-09-18/19; code fixes
shipped 2026-09-19 — see [RISK-REGISTER.md](RISK-REGISTER.md) B1/H2 for what changed and why.

**Status as of 2026-09-19:** the vendor-imagery embedding issue (36 counties, marked "✅ Fixed" below)
and the owner/mailing-address exposure for 10 counties (also marked "✅ Fixed") have both been
corrected in code and verified in a running browser — see [RISK-REGISTER.md](RISK-REGISTER.md). Dodge
and Goodhue still expose owner/mailing-address fields on their direct parcel services; that was a
deliberate decision to leave as-is for now, not an oversight.
