# Step 13 — Coordinates, Identify, and Map Inspection

## Goal
Make the map useful for precise field/recreation reference without yet building a large toolbox.

## Requirements
- Live cursor latitude/longitude display on desktop.
- Click/tap coordinate readout.
- Copy coordinates button.
- Choose at least decimal degrees initially.
- Drop a temporary inspect marker on click.
- Identify visible vector layers at the clicked location.
- Show terrain/elevation value if straightforward from the elevation service.

## Later coordinate formats
- DMS
- UTM
- Minnesota county coordinate systems if there is a real need

## Acceptance criteria
- User can click anywhere and copy coordinates.
- Parcel/public-land identification can share the same inspection popup/panel.
