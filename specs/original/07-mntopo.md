# Step 07 — MnTOPO, Hillshade, and Contours

## Goal
Supplement aerial imagery with useful topographic visualization from MnTOPO/MnGeo services.

## Layers to investigate/add
- lidar hillshade
- elevation color relief if useful
- contours
- topo/reference maps
- other MnTOPO layers that materially improve recreation or terrain interpretation

## Requirements
- Keep each useful layer independently toggleable.
- Allow hillshade over aerial imagery using opacity.
- Clearly label contour interval/source when known.
- Avoid loading redundant decorative layers that add little value.

## Acceptance criteria
- User can overlay hillshade on aerial imagery.
- At least one useful topo/contour layer is available.
- Layer opacity allows terrain features to remain visible without hiding imagery.
