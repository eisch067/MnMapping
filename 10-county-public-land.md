# Step 10 — County Public-Land Supplements

## Goal
Fill public-land gaps that statewide layers do not capture well, especially county-managed and tax-forfeited recreation lands.

## Initial counties
- Hubbard
- Beltrami
- Becker
- Todd
- Douglas

## Requirements
For each county, investigate:
- county-owned recreation land
- tax-forfeited land
- county forest lands
- local parks/open space where useful

Add only authoritative sources with understandable access implications.

## Adapter design
County public-land layers belong in the same county config/adaptor used for imagery and parcels.

## Acceptance criteria
- County-specific public-land additions appear under the normal Public Land layer group.
- No county-specific UI code is required.
